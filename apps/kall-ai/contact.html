Quick Carrier Forwarding Help

Airtel MMI error when dialing? Ensure Wi-Fi calling is momentarily disabled while activating, or run the code directly via your native phone dialer: *67*01141182702#.
Reliance Jio Forwarding: Jio uses unconditional *401*<number> or conditional *403*<number>. To cancel Jio forwarding, dial *402.
Universal GSM Deactivation: Dialing ##002# cancels all conditional and unconditional forwardings on Airtel, Vi, and BSNL immediately.
